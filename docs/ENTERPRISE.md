# 企业研发效能与DevOps平台企业能力

## 领域覆盖

- **代码仓库**：登记仓库、分支策略、代码所有者和合并规则
- **流水线**：编排构建、测试、扫描、制品和部署阶段
- **制品管理**：管理版本、哈希、来源、签名、保留和推广
- **环境管理**：维护开发、测试、预发和生产环境及配置差异
- **测试质量**：汇总单元、集成、端到端和回归测试结果
- **安全门禁**：执行依赖、镜像、代码和密钥扫描及例外审批
- **发布管理**：管理发布单、变更窗口、审批、版本说明和回滚
- **部署编排**：支持分批、蓝绿、金丝雀部署和自动回退
- **效能度量**：统计交付周期、部署频率、失败率和恢复时间

## 横向控制基线

- ADMIN 与 OPERATOR 权限分离，管理员审批由服务端强制校验；
- 模块白名单、字段约束、唯一编号、乐观锁和合法状态迁移；
- 企业控制项支持组织、期间、责任人、风险、期限和幂等键；
- 经办与复核职责分离，办结前至少登记一份带 SHA-256 的业务凭证；
- 外部系统同步保存成功、失败、回执编号和审计详情；
- 支持组合检索、分页、逾期筛选、CSV 导出、评论与时间线；
- `/api/domain/decision` 对企业研发效能与DevOps平台关键场景返回决策、0–100评分、计算指标和处置动作；
- prod profile 对默认账号密码、数据库口令和不安全跨域来源执行启动门禁。

## 生产适配

真实 `SCM`、IAM、消息、对象存储和第三方供应商接口只预留集成边界，由部署企业自行配置。生产上线前必须完成权限矩阵、数据映射、容量压测、灾备演练、安全评估与用户验收。
